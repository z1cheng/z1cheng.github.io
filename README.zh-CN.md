# z1cheng.github.io

陈辰的个人主页：<https://z1cheng.github.io>。一个人、一只名叫气气的橘猫、一个按钮唤起的终端。

## 页面与猫

- 单页展示个人信息与气气，右上角的文字入口唤起终端。桌面端从底部展开，手机端接近全屏，背景变暗并模糊。
- 终端使用原生模态对话框，打开时焦点保留在面板内；关闭后恢复焦点，命令记录与草稿保留。
- 深色网格、琥珀色点缀，支持浅色与跟随系统的主题，适配手机。
- 保留原来的橘白 SVG 猫和视线跟随。点击猫、按撸猫按钮、用鼠标轻轻拖动都能互动。摸头、摸下巴有不同反馈；手机轻触撸猫，滑动仍可滚动页面。
- 18 秒无操作开始犯困，30 秒自动入睡。操作页面会唤醒自动打盹的猫；主动让它睡觉后，需要撸猫、点击唤醒按钮或输入 `wake` 叫醒。
- 页面、猫咪反馈、终端帮助和错误提示默认使用中文；命令名保留常用英文。问候与名字默认显示英文，鼠标透镜里显示中文名，键盘聚焦时显示完整中文名，手机触摸时短暂显示透镜。
- 以图标配上邮箱、公司、地区与 GitHub 用户名，配有中国实时钟，以及保存在访客本机的撸猫次数。
- 尊重系统的“减少动态效果”设置，也可用终端命令 `motion off` 暂停动效；后台页面停止动画与定时更新。

## 33 个终端命令

终端是浏览器里的互动区域，不会执行系统命令，也不调用外部 API。链接命令会输出可点击链接，由访客决定是否打开。

| 分类 | 命令 |
| --- | --- |
| 探索 | `help [命令]`、`whoami`、`about`、`projects`、`github`、`email`、`ls`、`cat [文件]`、`pwd`、`tree` |
| 逗猫 | `pet [head\|chin]`、`feed`、`sleep`、`wake`、`status`、`meow`、`sudo pet` |
| 工具 | `date`、`time`、`calc <表达式>`、`echo <文本>`、`base64 encode\|decode <文本>`、`uuid`、`roll [面数]`、`fortune` |
| 会话 | `theme [dark\|light\|auto]`、`motion [on\|off]`、`uptime`、`history`、`neofetch`、`banner`、`clear`、`exit` |

可以先试：

```text
pet chin
calc (2 + 3) * 4
base64 encode "你好，猫"
cat dreams.txt
theme light
```

- **Tab**：补全命令和参数，再按一次切换候选。空输入框和 Shift+Tab 保持正常焦点导航。
- **↑ / ↓**：回看最近 50 条命令，向下回到末尾可恢复输入草稿。
- **⌘/Ctrl K** 或 **反引号**：打开并聚焦终端。反引号快捷键只在文本输入区之外生效。
- **Ctrl C**：未选中文字时取消当前输入。**Esc**：关闭终端。
- 右上角可展开终端；`exit` 收起终端并保留命令记录。
- `ls`、`pwd`、`tree`、`cat` 浏览的是虚拟文件，不访问用户文件系统。计算器使用算术解析器；输出以文本插入，最多保留 160 条。

## 文件与本地预览

`index.html` 放页面结构与原始 SVG，`style.css` 放响应式主题和动画，`app.js` 放猫咪状态与命令注册表。没有运行时依赖、外部资源或构建步骤。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173>。

开发依赖 jsdom 仅用于 DOM 交互测试：

```sh
npm ci
npm run check
npm test
```

测试覆盖打盹与手动睡眠、撸猫、存储不可用、主题、键盘操作、计算器、UTF-8 Base64、参数校验及安全文本输出。视觉调整后还应在浏览器检查响应式布局。

## 部署

GitHub Pages 从 `master` 根目录提供页面。部署时让 `index.html`、`style.css`、`app.js` 位于同一目录；`.nojekyll` 跳过 Jekyll。线上不需要 Node 或 `node_modules`。
