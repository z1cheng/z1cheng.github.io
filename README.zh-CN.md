# z1cheng.github.io

一个单页个人主页：<https://z1cheng.github.io>

## 页面上有什么

- 一只橘白相间的猫，全部用内联 SVG 画成。它的瞳孔会跟随鼠标，每隔几秒眨一次眼，头也会随着视线轻轻转动。
- 一句问候，平时显示 `Hi, I'm Chen Chen.`，鼠标移到标题上时，一个跟随光标的圆形透镜会在经过处露出 `你好，我是陈辰。`
- 一行个人信息 —— 邮箱、地区、实时本地时间、公司、GitHub。

## 实现方式

`index.html` 就是整个站点。没有构建步骤，没有依赖，也不加载任何外部资源：样式、脚本和插画全部内联。

**透镜**由一个 CSS 自定义属性同时驱动两处。`--r` 用 `@property` 注册过，所以可以在 hover 时从 `0` 平滑动画到透镜半径；同一个值既喂给 `clip-path: circle(...)` 用来露出中文层，也用来定位那块盖住英文的实心圆片。两者共用一套几何，所以「看得见的圆」和「文字真正切换的范围」不可能对不上。透镜横向跟随鼠标，纵向锁定在文字行的中心线——标题只有一条水平带，让它自由浮动的话圆会跑到文字下面去。

**眼睛**是一个 `requestAnimationFrame` 循环。鼠标位置先换算成 SVG viewBox 坐标，再缓动逼近目标，最后以 translate 作用在每只瞳孔分组上。每只瞳孔都被裁剪在自己的眼型里，所以虹膜不会跑出眼眶。

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 部署

GitHub Pages，从 `master` 分支根目录部署。`.nojekyll` 告诉 Pages 跳过 Jekyll 构建，按提交的原样提供文件。
